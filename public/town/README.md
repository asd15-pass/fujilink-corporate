支給時の `car-sprite.png` には切り抜き時の背景（街灯のポール・影の線・クリーム色の欠片）が
残っていたため、車体の4色（オレンジ #E8734A / 紫 #6E5AA8 / 水色 #BBD4E4 / 黒 #2E2B33）
だけを残して透過させ、最大連結成分以外を捨てたものに差し替えている。

## 差し替え方

同名・同サイズで置き換えれば、マークアップの変更は不要。
サイズを変える場合は `src/components/sections/HeroTown.tsx` の定数表と、
座標を持つ `src/app/town-animations.css` の `@keyframes` を合わせて更新する。

`base-trans.png` は本体とパッチ（人物・木・クレーン・バンの切り抜き）で共有しているため、
差し替えると `HeroTown.tsx` の `PATCHES` の矩形座標も要確認。
